# Personal Portfolio Website

This project was developed as part of my internship at CodeAlpha.

## Description
The Personal Portfolio Website showcases my skills, projects, and contact information in a modern and visually engaging layout. The site includes multiple sections such as Home, About Me, Projects, and Contact, allowing visitors to learn more about me and my work.

## Features
- Responsive design for different screen sizes
- Smooth navigation between sections
- Animated elements for enhanced visual appeal
- Structured presentation of personal information and projects
- Contact section for easy communication

## Technologies Used
- HTML
- CSS
- JavaScript

## Learning Outcomes
Through this project, I gained experience in:
- Designing and structuring multi-section websites
- Implementing animations using CSS and JavaScript
- Creating responsive layouts
- Improving UI/UX design skills
- Organizing personal projects in a professional format
